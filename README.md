# holyszewski.github.io

The landing page of [holyszewski.github.io](https://holyszewski.github.io/): a list of my projects
on GitHub Pages. One static `index.html` (English with a Czech switch) and the screenshots in `img/`.

- [Wolf80](https://holyszewski.github.io/Wolf80/): emulator of Czechoslovak single-board computers
- [microHAMCLOCK](https://holyszewski.github.io/microHAMCLOCK/): ham radio clock for the Heltec WiFi LoRa 32 V3
- Wolf's SFMT: emulator of the Science Fair Microcomputer Trainer (coming soon)
